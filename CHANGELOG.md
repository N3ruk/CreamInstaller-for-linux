# Changelog

## 1.0.0 — First public release

- Native Qt interface with polished compact layout.
- Multi-library Steam discovery through `libraryfolders.vdf`, including external drives and Flatpak Steam.
- Duplicate game installations grouped into one entry while retaining every detected route.
- Heroic / Legendary Epic discovery.
- CreamAPI and SmokeAPI support for Steam; ScreamAPI support for Epic.
- DLC metadata lookup, caching and per-game selection persistence.
- Original DLL backup and restore workflows.
- Proton, Steam Linux Runtime, Steamworks redistributables, Lossless Scaling and other non-game Steam entries are filtered.
- Easy Anti-Cheat and BattlEye titles remain visible and are flagged instead of silently excluded.
- Games without a compatible target DLL remain visible with a clear status.
- Neutral DLC-unlocker desktop icon with no Steam branding.
- Universal installer, Debian package builder and x86_64 AppImage builder.
